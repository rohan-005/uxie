# UXIE — Developer Power Cards

UXIE is a frontend web application that transforms developer activity, competitive coding milestones, and commit telemetry from GitHub, Codeforces, LeetCode, and CodeChef into dynamic, collectible Power Cards.

## Design Source of Truth
- **Stitch Project ID**: `10723860823950580510`
- **Design System**: Carbon & Obsidian telemetry theme, Geist/Space Grotesk typography, 3 Sports Card Formats (Grid Racing, Ultimate Shield, Court Hardwood).
